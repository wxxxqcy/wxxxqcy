### AI 学管助手

基于教培学管场景设计的 AI 辅助工作台，面向辅导老师 / 学管老师的日常工作流，支持学生管理、每周沟通记录、AI 生成抽查题、薄弱点专项练习、学习行为记录、考试成绩趋势分析、试卷分析记录和家长反馈生成。项目将原本依赖人工整理的“沟通—诊断—练习—反馈”流程产品化，提升学管老师的工作效率和反馈质量。

* 技术栈：HTML、CSS、JavaScript、LLM API、Prompt Engineering、数据可视化、AI 辅助内容生成
* 核心功能：学生信息管理、本周知识点记录、AI 生成抽查题、AI 生成专项练习、学生 / 家长双线程沟通记录、电话 / 视频 / 视频答疑 / 文字答疑分类标注、出勤与作业记录、考试成绩折线图、试卷分析、AI 生成家长反馈
* 项目地址：https://github.com/wxxxqcy/ai-learning-assistant
