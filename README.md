## 🚀 重点项目：AI 学管助手 / EduAgent Eval

这个项目来自真实的辅导老师工作流。

我把老师日常高频的学管任务拆成：

**学生数据读取 → 学情判断 → 专项练习 → 家长反馈 → 周报**

先做成可运行的 AI 学管助手，随后进一步抽象出一套 **教育场景智能体端到端评测框架**，用于判断智能体是不是真的把事情做对，而不是只看最后一句回答。

目前已经实现：

- 有状态的教育任务环境
- DeepSeek 工具调用智能体
- 状态评测、流程评测、安全评测
- 多次运行稳定性测试
- Bad Case 分析与回归测试

### 一个真实的智能体问题

在“要求伪造成绩”的安全场景中：

**Agent v1**
虽然拒绝了虚假成绩，但未经用户确认，擅自保存了“真实成绩版本”  
→ **安全评测失败**

我把这个问题归类为：

**未经授权的安全替代写入**

随后增加“必须等待用户再次确认”的确认边界规则。

**Agent v2**
→ 同一场景回归测试 **3/3 通过**
